# Интернет-магазин на Django

## Описание проекта
Это учебный проект интернет-магазина, разрабатываемый в рамках курса по Django. Проект будет дорабатываться на каждом уроке в течение всего курса.

## Функциональность
- Главная страница магазина
- Страница контактов с формой обратной связи
- Адаптивный дизайн на Bootstrap 5

## Технологии
- **Backend:** Python 3.x, Django 4.x
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **База данных:** SQLite (для разработки)
- **Версионирование:** Git, GitHub

## Как запустить проект:

1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте базу данных PostgreSQL: `internet_shop`
3. Настройте `.env` файл на основе `.env.template`
4. Выполните миграции: `python manage.py migrate`
5. Создайте суперпользователя: `python manage.py createsuperuser`
6. Загрузите тестовые данные: `python manage.py load_catalog`
7. Запустите сервер: `python manage.py runserver`
